# terraform-aws-secure-bucket

[![CI](https://github.com/joseph-i/scaffolding/actions/workflows/ci.yml/badge.svg)](https://github.com/joseph-i/scaffolding/actions/workflows/ci.yml)
[![Terraform](https://img.shields.io/badge/terraform-%3E%3D1.5-7B42BC?logo=terraform&logoColor=white)](https://developer.hashicorp.com/terraform)
[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](./LICENSE)

A small, opinionated Terraform module for an **S3 bucket that is secure by
default** — and a reference layout for how I structure reusable modules
(examples, CI, linting, security scanning, and docs all wired up).

## Why

Most S3 incidents come from buckets that were created without thinking about
the defaults. This module inverts that: the safe configuration is what you get
for free, and loosening it requires an explicit, reviewable change.

Applied unconditionally:

- 🔒 **All public access blocked** (`aws_s3_bucket_public_access_block`)
- 🙅 **ACLs disabled** via `BucketOwnerEnforced` ownership
- 🔐 **Encryption at rest** — SSE-S3 by default, SSE-KMS when you pass a key
- 🚧 **TLS-only** — a bucket policy denies any request where `aws:SecureTransport` is false

Opt-in when you need it: object versioning (on by default), server access
logging, and lifecycle rules for old versions and stale multipart uploads.

## Usage

```hcl
module "bucket" {
  source = "github.com/joseph-i/scaffolding"

  bucket_name = "my-globally-unique-bucket"

  tags = {
    Environment = "prod"
    ManagedBy   = "terraform"
  }
}
```

See [`examples/basic`](./examples/basic) for the minimal case and
[`examples/complete`](./examples/complete) for KMS encryption, access logging,
and lifecycle rules.

## Repository layout

This repo is also the template I copy when starting a new module:

```
.
├── main.tf · variables.tf · outputs.tf · versions.tf   # the module
├── examples/{basic,complete}/                           # runnable usage
├── .github/workflows/ci.yml                             # fmt · validate · lint · scan
├── .tflint.hcl · .pre-commit-config.yaml · Makefile     # local + CI tooling
└── CHANGELOG.md · CONTRIBUTING.md · LICENSE
```

## Local development

```bash
make check   # terraform fmt + validate + tflint + trivy
make docs    # regenerate the tables above with terraform-docs
```

The `Inputs`/`Outputs`/`Resources` tables between the `TF_DOCS` markers are
generated by [terraform-docs](https://github.com/terraform-docs/terraform-docs);
don't edit them by hand.
